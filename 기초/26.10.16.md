# 폴더·파일 관리와 7일 정리

## 오늘 정리한 내용

폴더 존재 여부에 따라 저장 환경을 준비하고, 파일을 확장자별로 분류한다.

## 실습 A: 다운로드 폴더 준비

1. 기준 폴더 경로를 String 변수로 관리한다.
2. Folder Exists의 결과를 Boolean 변수에 저장한다.
3. 폴더가 없으면 Create Folder를 실행한다.
4. 폴더 경로와 파일 이름을 결합한다.
5. 저장 후 실제 파일 존재를 확인한다.

VB 표현식:

```vb
Not folderExists
System.IO.Path.Combine(folderPath, "Vendor.xlsx")
```

경로 결합에는 `Path.Combine`을 사용한다. 경로 문자열 생성과 실제 폴더 생성은 별도 작업이다. [공식 문서](https://learn.microsoft.com/en-us/dotnet/api/system.io.path.combine)

## 실습 B: 파일 분류

| 확장자 | 이동 대상 예시 |
|---|---|
| .xlsx | Excel |
| .pdf | PDF |
| .docx | Word |
| 기타 | 원본 유지, 확인 대상으로 기록 |

구성: For Each File in Folder → Switch → Move File.

이동 전 대상 폴더를 준비하고, 목적지에 원래 파일 이름을 포함한다. 지정하지 않은 확장자는 원본에 남겨 두는 기준으로 정리했다.

## 재실행 기준

- 원본 파일의 복사본으로 실습한다.
- 분류된 하위 폴더가 다시 탐색되지 않도록 범위를 확인한다.
- 대문자·소문자 확장자의 처리 기준을 통일한다.
- 동일 이름이 있으면 덮어쓰지 않고 확인 대상으로 남긴다.
- 이동 실패 시 원본과 목적지를 확인하고 성공으로 기록하지 않는다.

## 검증 체크리스트

- [ ] 폴더가 없는 상태에서 생성됨
- [ ] 기존 폴더가 있는 상태에서도 다음 작업 진행
- [ ] 확장자에 맞는 폴더로 파일 이동
- [ ] 이동 후 원본 위치와 대상 위치 확인
- [ ] 기타 확장자는 정한 정책대로 처리
- [ ] 동일 이름 충돌 시 기존 파일 보존
- [ ] 재실행 시 이미 분류한 파일을 불필요하게 재처리하지 않음

## 7일 개념 정리

변수는 데이터를 연결하고, 조건문은 처리 경로를 나누며, 반복문은 여러 대상을 처리한다. 웹에서 추출한 DataTable은 엑셀 가공으로 이어지고, 파일 관리는 결과가 저장될 위치를 준비한다.
