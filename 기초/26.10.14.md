# Excel 읽기·쓰기와 필터링

## 오늘 정리한 내용

엑셀 데이터를 DataTable로 읽고 조건에 맞는 행과 열을 결과 파일에 저장한다.

## 기본 구조

```text
Excel Process Scope
 └─ Use Excel File: Export.xlsx
     └─ Read Range → dtExport
데이터 가공 → dtResult
Use Excel File: Export_Result.xlsx
 └─ Write DataTable to Excel
```

공통 변수가 각 작업 범위에서 접근 가능한지 확인한다.

## 필터 조건 정리

| 방식 | 행 조건 | 결과 |
|---|---|---|
| Excel Filter | Total > 100000 AND Total < 300000 | 조건에 맞는 범위 |
| For Each Row + If | Total < 80000 OR Total > 500000 | 조건에 맞는 행 |
| Filter Data Table | Vendor에 FR 포함 | Vendor, Month, Total 열 |

서로 다른 조건의 예제이므로 결과 행 수가 같아야 하는 것은 아니다.

## 표현식과 구조 메모

VB 예시:

```vb
dtExport.Rows(2).Item(3).ToString()
CurrentRow.ItemArray
{CurrentRow.Item("Vendor"), CurrentRow.Item("Tax"), CurrentRow.Item("Total")}
```

- DataTable 인덱스는 0부터 시작한다.
- `ItemArray`는 이미 배열이다.
- 특정 열만 새 배열로 만들면 결과 테이블의 열 순서도 동일하게 준비한다.
- Total은 실제 값의 숫자 변환 가능 여부와 빈 값을 확인한다.

## 경계값 확인

| Total 예시 | 100000 초과·300000 미만 | 80000 미만 또는 500000 초과 |
|---|---|---|
| 70000 | 제외 | 포함 |
| 80000 | 제외 | 제외 |
| 100000 | 제외 | 제외 |
| 200000 | 포함 | 제외 |
| 300000 | 제외 | 제외 |
| 500000 | 제외 | 제외 |
| 600000 | 제외 | 포함 |

위 표는 경계 조건을 이해하기 위한 예시 값이다.

## 혼동 방지

`Contains("FR")`와 `StartsWith("FR")`는 다르다. `AB-FR`을 포함해야 한다면 시작 문자열 조건만으로는 부족하다.

## 검증 체크리스트

- [ ] 헤더와 DataTable 열 이름 확인
- [ ] 원본·결과 파일 참조 구분
- [ ] AND/OR와 경계값 확인
- [ ] 결과 테이블의 열 수·순서·자료형 확인
- [ ] 필터 후 복사 범위와 저장된 행 수 확인

## 오늘의 정리

조건을 말로 먼저 정의하고 식으로 옮긴 뒤 경계값으로 확인한다. 데이터 가공 단계와 파일 쓰기 단계를 분리하면 결과를 점검하기 쉽다.
