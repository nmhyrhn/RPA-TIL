# Excel·Web 연동과 집계

## 오늘 정리한 내용

엑셀 행을 웹 검색 입력으로 사용하고, 조회 결과와 집계 결과를 구분해 저장한다.

## 실습 A: 특허정보 조회

- 입력: 특허정보.xlsx의 검색결과 시트, 출원번호 열
- 반복: For Each Excel Row
- 처리: 현재 번호 읽기 → 웹 입력 → 조회 → 표 추출
- 출력: 번호에 대응하는 시트에 결과 표 저장
- 확인 기준: 입력 번호와 결과 표의 정보가 일치하는지

헤더 설정을 확인한다. 출원번호는 식별값이므로 문자열 형식과 구분 기호, 앞자리 0 보존 여부를 확인한다. 번호 분할 위치는 입력 형식을 확인한 뒤 정한다.

## 실습 B: VLookup과 피벗

1. Employee.xlsx의 Sheet1에 Age 열을 준비한다.
2. 현재 행의 Employee ID로 Sheet2를 조회한다.
3. 반환할 나이 열의 인덱스를 조회 범위 기준으로 설정한다.
4. 결과를 현재 행의 Age에 저장한다.
5. 피벗테이블을 생성한다.

| 피벗 영역 | 필드·설정 |
|---|---|
| 행 | Department |
| 열 | Gender |
| 값 | Age |
| 집계 | 최소값 |

의미: 부서·성별 그룹의 최소 나이. 평균·합계·인원수와 구분한다.

## 파일 처리 방식

| 방식 | 이번 학습의 용도 |
|---|---|
| Use Excel File | Excel 앱을 이용한 조회·피벗 등 |
| Read Range Workbook | 파일 범위를 DataTable로 읽기 |
| Write Range Workbook | 지정한 위치에 데이터 쓰기 |
| Append Range Workbook | 기존 데이터 뒤에 추가 |

Workbook 액티비티의 설치 요건과 범위는 [공식 문서](https://docs.uipath.com/activities/other/latest/productivity/workbook-activities)를 참고한다. 파일 경로와 Workbook 참조 옵션은 [Read Range Workbook 문서](https://docs.uipath.com/activities/other/latest/productivity/read-range)에서 확인할 수 있다.

## 검증 체크리스트

- [ ] 각 행의 번호가 검색창에 정확히 입력됨
- [ ] 조회 결과가 현재 번호에 대응함
- [ ] 다음 반복에서 이전 입력·결과가 섞이지 않음
- [ ] 동일 시트 재사용 시 덮어쓰기 정책 확인
- [ ] VLookup의 ID 일치와 미일치 사례 확인
- [ ] 피벗의 원본 범위와 최소값 집계 확인

## 추가 개선 후보

검색 결과 없음 처리, 중복 ID 확인, 처리 건수 기록, 재실행 시 결과 보존은 기본 실습 이후 확장할 항목이다. 성능 비교는 같은 입력과 같은 결과를 전제로 측정한다.
