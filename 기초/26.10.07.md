# RPA와 Studio 기초

## 오늘 정리한 내용

RPA의 구성 요소를 구분하고, Studio에서 최소 워크플로우를 구성하는 방법을 정리한다.

## 핵심 개념

| 항목 | 정리 |
|---|---|
| Studio | 프로세스 개발 도구 |
| Robot | 자동화 실행 구성 요소 |
| Orchestrator | 실행·모니터링 등 운영 관리 |
| Activity | 클릭, 입력, 출력 등 작업 단위 |
| Sequence | 순서대로 수행할 작업을 담는 구조 |

## 실습 구성

- 프로젝트 예시: `Day01_HelloRPA`
- 입력: 문자열 `"Hello RPA"`
- 순서: Message Box → Write Line
- 예상 결과: 팝업 확인 후 Output 패널에 같은 문자열 표시
- 사용 패키지: 필요한 기본 액티비티가 제공되는 System 패키지 확인

## 액티비티 선택 기준

`Message Box`는 사용자가 즉시 확인해야 할 값에, `Write Line`은 개발 중 값과 흐름을 확인할 때 사용한다. 팝업을 닫아야 다음 단계로 진행하는 구성이라면 무인 실행 시 대기가 생길 수 있다.

## 문제 점검 메모

| 증상 | 먼저 확인할 항목 |
|---|---|
| 다음 작업으로 진행하지 않음 | Message Box가 열려 있는지 |
| 문자열 입력 오류 | 큰따옴표와 표현식 입력 상태 |
| 로그가 보이지 않음 | 실행한 파일과 Output 패널, 실행 경로 |
| 액티비티 검색 실패 | 패키지 설치 상태와 검색어 |

## 검증 체크리스트

- [ ] 프로젝트 생성과 저장 위치 확인
- [ ] Message Box에 예상 문장 표시
- [ ] 팝업 확인 후 Write Line 실행
- [ ] Output 패널에서 문장 확인

## 오늘의 정리

자동화는 작업을 실행하는 흐름과 결과를 확인하는 방법을 함께 설계해야 한다. 출력 액티비티는 이후 변수·조건문 실습에서도 중간 값을 확인하는 도구가 된다.
