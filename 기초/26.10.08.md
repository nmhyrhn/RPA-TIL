# Day 02 | 변수와 제어 흐름

## 오늘 정리한 내용

변수의 자료형과 범위를 설명하고 조건문·반복문을 목적에 맞게 선택한다.

## 자료형과 범위

- `String`: 검색어, 파일명처럼 문자로 다룰 값
- `Int32`: 횟수와 정수
- `Double`: 실수
- `Boolean`: 조건의 결과
- `String[]`: 여러 문자열을 순서대로 저장
- Scope: 변수를 읽고 쓸 작업을 포함하는 범위로 설정

## 표현식 메모

아래는 VB 표현식 예시이며, C# 프로젝트에는 문법을 그대로 붙여 넣지 않는다.

```vb
"Hello RPA"
age >= 20
number < 5
number + 1
{"사과", "오렌지", "딸기", "포도", "바나나"}
"선택한 과일: " & fruit
```

Assign에서 왼쪽 대상과 오른쪽 값을 구분한다. 예를 들어 대상은 `number`, 값은 `number + 1`이다.

## 실습

1. String 배열 `fruits`를 만들고 과일 5개를 저장한다.
2. For Each에서 배열을 순회한다.
3. 현재 항목을 `fruit`로 사용한다.
4. If의 조건을 `fruit = "사과"`로 설정한다.
5. Then과 Else에 서로 다른 Write Line을 배치한다.

예상 결과: 5회 출력, 사과 분기 1회, 나머지 분기 4회.

## 제어 구조 선택 기준

| 상황 | 선택 |
|---|---|
| 참·거짓 분기 | If |
| 한 값에 대한 여러 경우 | Switch |
| 조건이 유지되는 동안 반복 | While |
| 목록 전체 처리 | For Each |
| 횟수가 정해진 반복 | Repeat Number of Times |
| 순차적인 작업 | Sequence |
| 여러 경로를 시각적으로 연결 | Flowchart |

## 검증 체크리스트

- [ ] 배열 원소 수와 출력 횟수 일치
- [ ] 조건에 맞는 항목만 Then 실행
- [ ] While 사용 시 종료 조건과 값 갱신 확인
- [ ] 다른 Sequence에서 필요한 변수에 접근 가능

## 혼동 방지

문자열 `"20"`과 정수 `20`은 자료형이 다르다. 변수 인식 오류는 오타뿐 아니라 범위 문제일 수 있다. Switch의 Default는 처리하지 않은 입력을 확인하는 데 활용한다.
