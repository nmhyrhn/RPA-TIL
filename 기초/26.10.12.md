# 레코딩과 웹 자동화

## 오늘 정리한 내용

레코딩으로 생성된 흐름을 읽고, 클릭·입력·추출·저장 작업을 구분한다.

## 대표 실습: ACME 로그인

- 시작 조건: 계정 준비, 로그인 화면 표시, 브라우저 확장 상태 확인
- 구성: Use Application/Browser → Type Into 2개 → Click
- 예상 결과: 로그인 후 화면으로 이동
- 종료 설정: 후속 작업에 같은 창을 사용할 경우 닫기 설정 확인

## 응용 실습: 유니패스 공지사항

```text
사이트 열기 → 공지사항 이동 → 조회 조건 입력
→ 조회 → 화면 캡처 → 상세 내용 추출
→ 텍스트 저장 → 첨부파일 다운로드 → 저장 결과 확인
```

조회 조건과 메뉴 위치는 사이트 상태에 따라 달라질 수 있다. 현재 사이트에서 항목과 첨부파일 존재 여부를 확인하고 대상을 지정한다.

## 액티비티 메모

| 작업 | 액티비티 | 전달할 데이터 |
|---|---|---|
| 웹 작업 범위 | Use Application/Browser | 대상 브라우저 |
| 텍스트 입력 | Type Into | 문자열 |
| 항목 선택 | Select Item | 선택할 항목 |
| 텍스트 추출 | Get Text | 출력 String 변수 |
| 화면 캡처 | Take Screenshot | 출력 이미지 변수 |
| 텍스트 저장 | Write Text File | 경로와 본문 |

캡처 액티비티 실행만으로 이미지 파일 저장까지 끝났다고 판단하지 않는다. 이미지 파일이 필요하면 저장 단계를 추가한다.

## 증상별 점검

- 로그인 입력란을 못 찾음: 이미 로그인된 상태인지 확인.
- 브라우저가 닫힘: 상위 범위의 닫기 설정 확인.
- 다른 입력란에 입력됨: UI 재지정 또는 타겟 편집.
- 저장 대화상자가 안 뜸: 브라우저 다운로드 설정 확인.
- 파일 저장 실패: 폴더 존재, 전체 경로, 파일명 문자 확인.

## 검증 체크리스트

- [ ] 로그아웃 상태에서 로그인 흐름 확인
- [ ] 의도한 입력란과 버튼 지정
- [ ] 추출한 제목·본문이 선택한 항목과 일치
- [ ] 결과 파일이 지정한 폴더에 존재
- [ ] 공유할 파일과 이미지에서 실제 계정 정보 제거

## 오늘의 정리

레코딩은 흐름을 만드는 출발점이다. 실행 전 화면 상태와 브라우저 범위, 실행 후 결과까지 확인해야 재현 가능한 자동화가 된다.
